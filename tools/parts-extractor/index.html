    Every sheet is listed, including the ones that produced nothing. A sheet you expected showing “no parts table found” means its header row uses a spelling the dictionary does not know yet.

    What comes out

    Parts_Long is the table itself — source file, sheet, section banner, the nine descriptor columns, then Attribute (the model code) and Value (the quantity). Extraction_Log lists every sheet and what happened to it. QA_Check_Headers flags columns treated as models that look like descriptors — the early warning that a new spelling has appeared. QA_Model_Renames shows where a model code was spelled two ways and which spelling won. Model_Summary counts rows per file, sheet and model.
